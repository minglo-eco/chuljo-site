# 출조 — 앱 소개 사이트

낚시 물때 앱 "출조"의 소개 페이지와 법적 고지 문서입니다.

- `index.html` — 앱 소개
- `privacy.html` — 개인정보처리방침 (Google Play 필수)
- `terms.html` — 이용약관 (구독 결제 시 필요)

## 배포

GitHub Pages로 배포합니다. Settings → Pages → Source: `main` 브랜치 루트.

## 배포 전 확인

`class="fill"` 로 표시된 노란 자리를 전부 실제 사업자 정보로 바꿔야 합니다.
남아 있으면 페이지에 노란 배경으로 눈에 띄게 보입니다.
